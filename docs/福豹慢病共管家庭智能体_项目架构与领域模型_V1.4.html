02 · Bounded Contexts

领域模块与职责

家庭共管

以 Family 为协作边界；成员、邀请、健康档案、计划、读数、建议均受家庭授权与审计约束。

接口：身份解析、成员关系、档案编辑授权。

健康计划执行

Plan 生成 DailyTask；TaskRecord 记录完成或跳过。客户端可持有待同步变更，服务端是最终状态权威。

接口：计划管理、长辈任务记录、提醒投递。

健康事件与关怀

HealthReading 通过确定性 L1/L2 规则产生 Alert；LLM 不参与告警等级判定。

接口：健康录入、告警处理、关怀提醒。

设备与终端

当前模型将 Device 与 Family 绑定，覆盖发现、激活、设置、事件和命令记录；物理设备与家庭绑定分离是未来演进项。

生命周期拆分：规划

互动与火花

SparkActivity / SparkStatus、Topic、Message 形成家庭互动与双端展示能力；话题建议可由后台 Agent 命令产生。

健康助手

报告分析产生正式 Recommendation；普通问答只返回临时文本。客户端临时会话与服务端 Agent 执行是不同概念。

04 · Agent Execution

Agent 执行与健康助手模型

健康助手会话（Flutter 临时状态）

  • 进入页面到离开页面期间有效；重新进入即为新会话。
  • 报告分析与普通问答是封闭命令；普通问答最多传输最近 8 个成功轮次、16 条消息。
  • 报告分析不使用普通会话历史；普通问答成功文本不持久化。
  • 本地 OCR 只提取待核对候选值，图片与原文不上传至健康档案接口或 AI 服务。

AgentRun 执行模块（NestJS 权威）

  • 一个 AgentRun = 一次逻辑业务执行；一个 AgentRunAttempt = 一次真实 AI 调用。
  • Run 状态：PENDING → RUNNING → SUCCEEDED，或 RETRYING → RUNNING，或 FAILED。
  • Attempt 状态：STARTED → SUCCEEDED / FAILED / ABANDONED。
  • 交互命令只允许一次 Attempt；健康告警建议最多三次，使用数据库时间、租约与 fencing token。

AgentRun

AgentRunAttempt
Run + attemptNumber 唯一；记录状态、fencing token、稳定错误码、来源、延时；不记录异常原文或 Prompt。
Recommendation
一个 Run 至多一个正式建议；仅报告分析、健康告警和话题等正式产物持久化，普通问答不写入。
05 · Architecture Decisions

关键架构决定与当前边界

决定当前实现明确不应表述为已交付
NestJS 为执行生命周期唯一权威PostgreSQL 事务、原子 claim、租约、fencing、Run/Attempt/Recommendation 关系与 Outbox。Python 持久化 Run、Python 内部重试、取消状态或 AgentRun 轮询 API。
受控 AI 出口HMAC 服务认证、最小 Tool API、结构化输出与 SafetyGuard；模型从服务端目录显式解析。客户端直连模型、App 内模型密钥、完整 Prompt/原始输出持久化、自动诊断或用药调整。
本地优先 OCRFlutter 的 HealthDocumentRecognizer 抽象、ML Kit/浏览器本地实现、用户确认回填。远程 OCR 微服务、上传原图/原文、自动覆盖健康档案、真机 OCR 全量验收。
知识库与运行平台受控检索接口与当前可引用的 Mock 样本；Compose 部署含 PostgreSQL、Redis 与内部 AI service。pgvector 知识入库、生产医疗知识库、Kafka、Kubernetes、自动周期话题调度。

# 页面设计改动计划

日期：2026-10-12
基线：`main` / `74b5424`；开始时工作区干净。
范围：荣誉、项目详情、能力三个区域。沿用现有极光背景、玻璃控件、字体与事实边界。

## 设计目标与审查结论

网站面向希望快速判断工程能力的项目评审与招聘读者。页面要让读者先看清成果，再理解每个项目独有的问题、方案与证据。

现状：荣誉的竞赛标题远大于获奖结果，第三列内容稀少且重复层级；能力只有四段抽象短文；五个详情共用“系统链路 / 核心实现 / 设计取舍”的通用文案与结构。已有独立首屏图案不足以区别正文。

选择：将荣誉做成紧凑的成果凭证，将能力做成连接实际案例的交付地图，将详情正文改为研究任务、信任关系、任务时间线、掩码决策、文档对照与家庭角色等真实工作对象。

自我审查：不采用大数字仪表盘、雷达图、熟练度百分比或纯换色模板。唯一强调性的视觉处理放在荣誉的奖项大字；详情的示意只服务解释，能力的每项都连接现有案例。

## 视觉规格

- 色彩沿用现有变量：雾绿 `#eef1ed`、墨色 `#171c20`、深青 `#2f666b`、浅冰 `#b8e2e5`、兰紫 `#80659a`；荣誉用已有金色 `#b78335`。暗色使用现有对应变量。
- 字体：Noto Sans SC / Manrope 用于正文和中文标题；IBM Plex Mono 用于材料标签与流程注记；Cormorant Garamond 继续用于既有英文展示。
- 标题、奖项、正文分别建立清楚层级；获奖结果桌面约 44–56px，移动约 34px，长结果可换行。
- 保留玻璃材质，但减去荣誉卡片装饰水印与竖排年份；不新增背景动画。

## 1. 荣誉：先读结果，再读竞赛

桌面：
```
[层级 · 年份/届次]      [竞赛类别]
[     三等奖     ]      [竞赛全称]
[ THIRD PRIZE   ]      [关联项目 → / 独立竞赛荣誉]
                       [材料来源（低权重）]
```

- 从三列改为两列，左侧约 30% 为成果区，右侧约 70% 承载标题、项目入口与材料来源。
- 所有真实奖项保持现有排序与原文，不新增一等奖等未提供的荣誉。
- 长竞赛名降低字号，获奖结果升为卡片的视觉中心。
- 移动端改为上下两区，结果优先，避免极窄三列和竖排文字。
- 同步调整加载骨架与滚动入场选择器。

## 2. 项目详情：按问题决定正文结构

| 项目 | 核心问题 | 专属正文结构 |
| --- | --- | --- |
| PharmAgent | 如何让科研建议可追溯 | 保留研究证据链与原图；实现改成数据 / 模型 / 编排的交接记录 |
| 玄玑 | 三种发现工具分别解决什么问题 | 任务入口矩阵：输入、操作、研究输出；材料成果与未评估内容明确区分 |

| V2T | 长任务如何可观察、可恢复 | 视频到摘要的纵向任务时间线；状态事件与磁盘恢复并列说明 |
| Eliminate | 不确定人物应该删除还是保护 | 主体 / 路人 / 不确定三态决策板；删除掩码减保护掩码的约束说明 |
| ScholarWeaver | 论文结构与服务联通如何支撑翻译 | 保留原译对照与原图；实现改为文档处理层和个人可见贡献层的对照 |

- 公共首屏、返回导航、来源图库与资源入口保留；正文不再重复通用标题和同一种三卡网格。
- 事实、历史测试结果、未公开代码与合作贡献范围沿用已审核内容；不制造 UI 截图、运行日志、模型效果或新评测数字。
- 新增可复用的专属故事组件；避免把所有项目继续塞进同一通用流程组件。
- 历史审查结果明确为此前记录，本次只验证网站改动。
